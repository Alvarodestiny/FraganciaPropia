Armani Code Sport · Giorgio Armani

Alternativas baratas a Armani Code Sport

Armani Code Sport es un perfume masculino de Giorgio Armani de aromas frescos y cítricos. Destacan notas de menta, mandarina, limón, ginger flower, water notes y vetiver. La comunidad lo asocia sobre todo a verano y primavera y a la mañana y la tarde, con una presencia equilibrada. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
