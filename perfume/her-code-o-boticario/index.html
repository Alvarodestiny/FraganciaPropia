Her Code · O Boticário

Alternativas baratas a Her Code

Her Code es un perfume femenino de O Boticário de aromas dulces. Destacan notas de red wine, cereza, liquor, nardo, sándalo y gourmand accord. La comunidad lo asocia sobre todo a invierno y otoño y a la noche, con una presencia intensa. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
