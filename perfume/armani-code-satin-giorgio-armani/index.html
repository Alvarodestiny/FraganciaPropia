Armani Code Satin · Giorgio Armani

Alternativas baratas a Armani Code Satin

Armani Code Satin es un perfume femenino de Giorgio Armani de aromas dulces. Destacan notas de jengibre, sorbet, azahar, neroli, vainilla y cacao. La comunidad lo asocia sobre todo a invierno y otoño y a la noche, con una presencia intensa. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
