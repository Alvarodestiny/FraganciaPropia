Armani Code Profumo · Giorgio Armani

Alternativas baratas a Armani Code Profumo

Armani Code Profumo es un perfume masculino de Giorgio Armani de aromas ambarados, dulces y frescos. Destacan notas de cardamomo, green apple, nuez moscada, lavanda, haba tonka y ámbar. La comunidad lo asocia sobre todo a invierno y otoño y a la noche, con una presencia intensa. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
