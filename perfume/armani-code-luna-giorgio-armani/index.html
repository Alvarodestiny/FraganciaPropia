Armani Code Luna · Giorgio Armani

Alternativas baratas a Armani Code Luna

Armani Code Luna es un perfume femenino de Giorgio Armani de aromas dulces, cítricos y florales. Destacan notas de naranja amarga, bergamota, azahar, osmanthus, vainilla y haba tonka. La comunidad lo asocia sobre todo a otoño y a la tarde y la noche, con una presencia equilibrada. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
