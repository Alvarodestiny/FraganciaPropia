Armani Code Colonia · Giorgio Armani

Alternativas baratas a Armani Code Colonia

Armani Code Colonia es un perfume masculino de Giorgio Armani de aromas dulces, cítricos y ambarados. Destacan notas de bergamota, mandarina, azahar, clary sage, haba tonka y amberwood. La comunidad lo asocia sobre todo a primavera y verano y a la mañana y la tarde, con una presencia equilibrada. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
