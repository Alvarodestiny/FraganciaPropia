Armani Code Absolu · Giorgio Armani

Alternativas baratas a Armani Code Absolu

Armani Code Absolu es un perfume masculino de Giorgio Armani de aromas dulces y ambarados. Destacan notas de green mandarin, manzana, nuez moscada, azahar, vainilla y haba tonka. La comunidad lo asocia sobre todo a invierno y otoño y a la noche, con una presencia intensa. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
