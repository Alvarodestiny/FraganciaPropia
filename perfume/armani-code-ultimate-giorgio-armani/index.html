Armani Code Ultimate · Giorgio Armani

Alternativas baratas a Armani Code Ultimate

Armani Code Ultimate es un perfume masculino de Giorgio Armani de aromas dulces, florales y especiados. Destacan notas de star anise, pomelo, heliotropo, olive blossom, vainilla y haba tonka. La comunidad lo asocia sobre todo a invierno y otoño y a la noche, con una presencia intensa. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
