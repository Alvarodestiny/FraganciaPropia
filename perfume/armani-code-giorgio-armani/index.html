Giorgio Armani

Armani Code

Armani Code es un perfume masculino de Giorgio Armani de aromas especiados, cítricos y amaderados. Destacan notas de limón, bergamota, star anise, olive blossom, cuero y haba tonka. La comunidad lo asocia sobre todo a invierno y otoño y a la noche, con una presencia suave. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
