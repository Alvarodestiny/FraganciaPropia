Agent Provocateur · Agent Provocateur

Alternativas baratas a Agent Provocateur

Agent Provocateur es un perfume femenino de Agent Provocateur de aromas florales. Destacan notas de indian saffron, magnolia, moroccan rose, vetiver, almizcle y cedro. La comunidad lo asocia sobre todo a otoño y invierno y a la noche, con una presencia intensa. Por precio entra en el rango diseñador (normalmente entre unos 70 y 150 €).
